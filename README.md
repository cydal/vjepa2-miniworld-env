# MiniWorld → JEPA: Phase 1, environment + pilot video corpus

A small JEPA-style video representation model, inspired by V-JEPA/V-JEPA 2
but trained from scratch, on video generated by a controlled MiniWorld
environment rather than internet video. Full plan: [docs/phase1-plan.md](docs/phase1-plan.md).

This is a different project from [`ai-build-and-learn/topics/v-jepa`](../ai-build-and-learn/topics/v-jepa):
that one probes a **pretrained** V-JEPA 2 checkpoint on Kinetics clips.
This one trains a small JEPA-style model **from scratch** on
**procedurally generated** video, and the model itself is a later phase
(see "Explicitly out of scope" in the plan) -- what's here is the
environment wrapper and the pilot dataset.

## What's here

```
env_wrapper/    thin wrapper around miniworld.envs.OneRoom: per-episode
                geometry/appearance/clutter randomization, camera fixed
data_gen/       episode generation, overlapping clip extraction, storage
scripts/        smoke_test.py, generate_pilot.py, inspect_dataset.py
```

The model never sees anything in `env_wrapper`/`data_gen` beyond raw
frames -- position/orientation/goal/action metadata is recorded
(`meta.json` per episode) for evaluation only, per the brief's section 12.

## Setup

MiniWorld renders through Pyglet/OpenGL and needs a real GL context even
for `render_mode="rgb_array"`, so on a box with no display (this one) it
needs Xvfb, and mesa's `libGLU` (not installed by default on this
Ubuntu box -- `sudo apt-get install -y libglu1-mesa` first).

```bash
conda create -n miniworld python=3.11
conda activate miniworld
pip install -r requirements.txt

xvfb-run -a python scripts/smoke_test.py        # proves rendering works
xvfb-run -a python scripts/generate_pilot.py --n-episodes 500 --episode-len 100
python scripts/inspect_dataset.py --dataset-dir dataset/pilot   # no GL needed, just reads files
```

## Pilot results (2026-09-16)

500 episodes, 158.5s wall-clock, 36.1 MB on disk. 111/112 possible
wall/floor/ceiling texture-family combinations appeared; contact sheet at
`dataset/pilot/contact_sheet.png` (gitignored, regenerate with
`inspect_dataset.py`) shows clearly distinct rooms with the same task
structure. Details in [notes/journal.md](notes/journal.md) (gitignored, ask if you want the
contents).
